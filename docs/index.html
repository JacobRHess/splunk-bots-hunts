01AWS reconnaissance via compromised IAM user `bstoll`

On 2018-08-20, CloudTrail records 615 AWS API calls attributed to the IAM user bstoll originating mostly from 107.77.212.175 (an AT&T Mobility IP outside Frothly's normal range). The activity is broad rather than targeted: 64 distinct API actions across S3, EC2, IAM, and ELB, in a window of a few hours. Four of those calls are ConsoleLogin events, none of which used MFA.

04FYODOR-L PowerShell implant (Empire-style)

FYODOR-L.froth.ly is the loudest Sysmon host in the dataset, and the noise is a live PowerShell implant. The host runs powershell.exe -NonI -W hidden -c "IEX (...FromBase64String((gp HKLM:\Software\Microsoft\Network debug).debug)))". That one line carries the whole technique: read a base64 blob out of a registry value, decode it in memory, and run it with IEX. Nothing touches disk, so file-hash and AV signatures never get a look.
